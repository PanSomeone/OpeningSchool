# 开源大学（OpeningSchool）

模块化 Android 应用。主页可以进入所有功能，其余能力以插件形式安装、移除和单独设置；第三方可以通过独立 APK 提供教务适配器。

> 当前测试版：`1.0.0-beta1`（versionCode 2），发布包使用独立 release 密钥签名。
>
> 仓库：[PanSomeone/OpeningSchool](https://github.com/PanSomeone/OpeningSchool) · [问题反馈](https://github.com/PanSomeone/OpeningSchool/issues) · [版本发布](https://github.com/PanSomeone/OpeningSchool/releases)

## 功能

- 主页：2 列组件画布，默认 4 行（8 格），可加到 12 行（24 格）；组件支持 1×1、2×1、1×2、2×2，可添加、移除、长按拖动、留空。文件夹组件可装多个功能并自定义名称；内置天气、今日课程、日期、文件夹，插件提供热水和 GPA 组件；天气卡片可打开天气详情页
- 课表：多张独立课表，可切换、新建、重命名、单独删除；节次列同时显示上下课时间
- 课程：一门课可添加多个「星期 + 起止节次」时间段；支持周次 / 颜色 / 备注和跨节合并
- 周次：`‹ 第 N 周 ›` 切换，点周次可跳转；学期开始、总周数、一周起始日、周末显示可调
- 作息：节次数量、起止时间可调，可设置午休分割线；修改某节时长可自动顺延后面的节次
- 导入：学校列表（华中农业大学、自定义网址）→ 应用内网页 → 登录并打开课表页 → 页面右下角「导入」
- 网页解析：正方 `kbList` JSON、`#kbtable` HTML、通用表格（横排/纵排、rowspan、单双周）；导入前预览，可替换当前或新建课表
- 插件：独立「插件市场」按钮负责添加；已安装列表同时显示在导航栏和不在导航栏的插件，支持移除和设置
- 外观：浅色 / 深色 / 跟随系统，纯色 / 淡色 / 网格 / 图片背景，格子高度
- 壁纸：支持全局壁纸和按页面覆盖（主页、课表、热水、成绩、插件、设置）；页面壁纸优先于全局
- 悬浮导航：半透明外观，透明度可调；固定宽度的图标 + 名称，高亮条平滑滑动；排序、隐藏、改名、28 个可选图标；最多 5 项
- 成绩插件：GPA 先展示逐门成绩，勾选是否计入，点击「计算 GPA」后显示总体与每学期统计；可从教务成绩页登录后抓取成绩。另含体测标准分、加分、等级与毕业总评
- 热水插件：手机号 + 验证码登录、设备列表、开关水、设备绑定；主页有快捷开关组件
- 设置：主题、壁纸、导航、透明度，以及关于页（作者 PanSomeone、版本号、检查更新、赞助）
- 反馈与日志：反馈入口可打开仓库 Issues；导出日志会生成带版本、机型、系统与最近运行记录的文件，崩溃记录也会保留

## 构建与测试

需要 JDK 17+ 与 Android SDK（`compileSdk 37`，`minSdk 26`）。

```bash
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
./gradlew test
```

- Debug 产物：`app/build/outputs/apk/debug/app-debug.apk`
- Release 产物：`app/build/outputs/apk/release/app-release.apk`
- Release 签名读取根目录 `keystore.properties`（以及其中的 jks 路径）；这两个文件已被 `.gitignore` 排除，请自行备份，后续升级必须使用同一密钥。

## 数据位置

- 多课表：`filesDir/timetables.json`（写入临时文件后原子替换；旧的 `timetable.json` 会迁移）
- 设置、主页组件布局、壁纸映射、悬浮导航：SharedPreferences
- GPA 课程与计入开关：SharedPreferences（`openschedule_scores`）
- 课表插件背景图：`filesDir/background_*.img`
- 全局/页面壁纸：`filesDir/wallpaper_*.img`
- 运行日志：`filesDir/logs/app.log`（超过 256 KB 轮转为 `app.log.1`）；导出文件写入 `cacheDir/logs/`，由系统分享面板交给用户选择去向

## 教务网页导入

1. 课表页右上角「导入」→ 选择华中农业大学或填自定义网址。
2. 应用内打开官网，由用户自己登录，进入课表页。
3. 点页面右下角「导入」，读取当前页及同源 iframe 的 HTML。
4. 解析器依次尝试正方 JSON、正方 `#kbtable`、通用星期/节次表格；解析结果先预览。

- 不接管账号密码，不保存网页登录信息；抓取只在用户点「导入」时发生。
- 部分学校会拦截 WebView 登录或把课表放在跨域 iframe；遇到时请反馈具体学校与页面。
- 成绩导入在成绩插件里复用同一套登录 WebView；登录一次后 Cookie 会在应用内保留，课表与成绩页面通常共享登录状态。
- 内置学校地址可编辑；华中农业大学课程查询入口为 `http://byjxyt.hzau.edu.cn/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151&layout=default`。
- 华农使用统一身份认证，登录可能要求手机短信验证码。WebView 已启用第三方 Cookie、同窗口弹窗、Cookie 持久化和键盘避让；账号密码和短信验证码都由用户在官方页面输入，应用不保存。
- 成绩查询入口为 `http://jwgl.hzau.edu.cn/cjcx/cjcx_cxDgXscj.html?gnmkdm=N305005&layout=default`，已内置在成绩插件的导入面板。

## 成绩插件

### GPA

- 先展示逐门成绩，按学期分组；每门课可单独勾选是否计入 GPA。
- 点击「计算 GPA」后显示：总体 GPA、加权平均分、计入学分/门数，以及每个学期的 GPA 和学分。
- 公式：`GPA = Σ(学分 × 课程绩点) ÷ Σ学分`。
- 当前采用的 4.0 分段换算：90–100→4.0，85–89→3.7，82–84→3.3，78–81→3.0，75–77→2.7，72–74→2.3，68–71→2.0，64–67→1.5，60–63→1.0，<60→0。
- **这张表仍需要用华中农业大学官方成绩单背面的换算表核对**；插件设置里也写了同样的提示。
- 自动导入：GPA 页「导入」→ 华中农业大学（`http://jwgl.hzau.edu.cn/cjcx/cjcx_cxDgXscj.html?gnmkdm=N305005&layout=default`）或自定义成绩网址 → 统一认证登录（可能需要短信验证码）→ 打开成绩查询页 → 页面右下角「导入」。支持正方成绩表和 JSON 成绩响应，识别课程名、学分、成绩、学年/学期。
- 导入会先预览：可追加（按课程名+学分+成绩+学期去重）或替换全部；等级制成绩（优/良/中/及格）暂不换算，会在预览里提示跳过数量。成绩只保存在本机。

### 体测

- 单项权重：BMI 15%、肺活量 15%、50 米 20%、坐位体前屈 10%、立定跳远 10%、引体向上/仰卧起坐 10%、1000/800 米 20%。
- 总分 = 标准分 + 加分（最多 20，总分最多 120）；等级：≥90 优秀，≥80 良好，≥60 及格。
- 毕业总评 = 大四 50% + 前三年平均 50%。
- 输入是体测报告中的**单项得分**，不是原始跑步秒数/跳远厘米数。
- 依据：[华中农业大学《国家学生体质健康标准》实施办法](https://bksy.hzau.edu.cn/info/1039/1065.htm)、[环湖长跑规定](https://sport.hzau.edu.cn/info/1102/8658.htm)。
- 体育课总评（环湖跑、专项、理论、考勤等占比）尚未内置，需要「狮山有你」的算分页面或体育部最新文件确认后再补。

## 正方教务

- 面向新版正方（`xtgl/login_slogin.html`），账号密码 + csrftoken + RSA 加密密码登录。
- 优先解析 `kbList` JSON，退回 `#kbtable` HTML 表格。
- 若学校启用登录验证码，账号导入不可用，可改用网页导入或第三方适配器。
- 抓取不到开学日期时可在导入预览后到课表设置补填。

## 热水插件

由 `D:\798QuSiBa` 移植：

- 只调用官方 App 已在用的接口，不绕过付费、不伪造凭证、不攻击服务器；请仅操作本人有权使用的设备。
- 不复用官方 App 的 `cid`；每次安装生成独立的客户端 ID。
- 不保存密码；令牌存在本机 SharedPreferences。
- 不支持相机扫码，设备绑定通过手输设备码 / 二维码内容完成。
- 开阀后 3 秒内禁止重复开阀；会话失效（`-99`）会要求重新登录。

## 第三方适配器

适配器是独立 APK 中的 `Service`，通过 `Messenger` JSON 通信，宿主不加载任何外部代码。完整协议、清单声明与骨架代码见 [docs/ADAPTER_API.md](docs/ADAPTER_API.md)。

插件市场当前提供内置插件目录。后续选择的应用内插件包格式需要签名、沙箱与审核机制，尚未实现。

## 主页组件

- 固定两列网格，默认 4 行（8 格），编辑模式可添加到 12 行（24 格）。
- 每个组件支持 1×1、2×1、1×2、2×2；编辑模式点右下角缩放按钮选择大小，空间不足时不会强行覆盖，会在对话框里提示。
- 普通模式下拖动组件顶部的小横条即可换位，页面其他区域可以正常上下滚动；拖到空白区域即可留出中间空格。目标占用时会拒绝放下。编辑模式还提供添加、移除、缩放和文件夹设置。
- 页面标题与顶部文字跟随主题前景色，深色主题下不会出现黑色文字压在深色背景上。
- 点空白格从组件列表添加；点右上角 × 移除，格子会保留为空。
- 「文件夹」组件可以创建多个：编辑模式点左下角齿轮设置名称，并勾选要放入的功能。内容超出格子时，点文件夹标题或 +N 打开完整列表。
- 目前的内置组件：天气、今日课程、日期、文件夹；插件组件：热水快捷开关、GPA。第三方 UI 组件需要后续应用内插件包机制，不能通过现有适配器协议注入。
- 天气详情页由天气组件打开，包含湿度、风速和未来三天预报；天气数据来自 Open-Meteo，城市暂固定为武汉。

## 壁纸

- 设置 → 外观 → 壁纸：可设置一张全局壁纸，也可以给主页、课表、热水、成绩、插件、设置分别选图。
- 页面壁纸优先于全局；页面没有自定义图时自动跟随全局。
- 图片会复制到应用私有目录 `filesDir/wallpaper_*.img`，不申请存储权限；替换/移除时自动清理不再被引用的文件。
- 有壁纸时，课表插件内的纯色/网格/图片背景会暂时让位给壁纸；移除壁纸后恢复课表自己的背景设置。
